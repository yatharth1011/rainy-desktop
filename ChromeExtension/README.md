# Rainy for Chrome

Two pieces, both fed by the Rainy Desktop app (which must be running):

- **Rainy Tab** (`ChromeExtension/RainyTab`) -- New Tab page that renders
  Rainy's rain shader over the part of your wallpaper behind the browser
  window, on the desktop's own rain clock (so it reads as see-through), with
  Google search (+ suggestions) and shortcuts drawn as liquid-glass lenses.
  It loads instantly and never navigates by itself, so whatever you start
  typing in the address bar is never lost.
- **Rainy glass on any site** (same extension) -- click the Rainy Tab
  toolbar button or press ⌥⇧G on a site to toggle it: live rain behind the
  page, the page re-skinned as dark smoked glass. Off by default everywhere;
  remembered per site (Chrome asks once for access to that site so it can
  re-apply on reload). Toggling off restores the page exactly.
- **Rainy Theme** -- generated by the app into
  `~/Library/Application Support/RainyDesktop/ChromeTheme` from your current
  wallpaper (frosted, smoked tab strip + toolbar). Regenerated on every
  wallpaper change; Rainy Tab re-applies it automatically.

The app serves wallpaper/settings/clock on `http://127.0.0.1:47823`
(loopback only; see `Sources/RainyDesktop/Chrome/ChromeBridge.swift`).

## Install (once)

1. Open `chrome://extensions`, turn on **Developer mode** (top right).
2. **Load unpacked** -> choose `ChromeExtension/RainyTab`. When Chrome asks
   whether to keep the changed New Tab page, choose **Keep it**.
3. **Load unpacked** again -> press ⌘⇧G and paste
   `~/Library/Application Support/RainyDesktop/ChromeTheme` (the theme the
   app generates; run the app once first). Optional shortcut:
   `ln -s ~/Library/Application\ Support/RainyDesktop/ChromeTheme ChromeExtension/RainyTheme`.

Theme look (tab strip / toolbar darkness, frost, saturation) is under
**Chrome** in Rainy's settings; changes re-apply automatically.
